📘 What is a Logical Expression?

A logical expression is a combination of Boolean variables and logical operators that produces either TRUE (1) or FALSE (0).


Example: A AND B is a logical expression. It becomes TRUE only when both A and B are TRUE.


Truth tables are used in computer science, digital electronics, artificial intelligence and mathematics to show the result of logical expressions for every possible input combination.
